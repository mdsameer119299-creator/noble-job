# Fix: Stop Displaying Expired Government Jobs

## Summary

This pull request fixes critical government job expiration issues by:

1. ✅ **Preventing expired jobs from appearing** in listings (`/api/govt-jobs`)
2. ✅ **Filtering by last_date automatically** in both local and Supabase queries
3. ✅ **Only showing active jobs** - expired ones are filtered out transparently
4. ✅ **Auto-marking expired jobs** - cron endpoint marks jobs as `status='expired'`
5. ✅ **No UI changes** - output format remains identical
6. ✅ **No notification/auth changes** - only affects job filtering

---

## Problem

Government jobs with hardcoded dates in June 2026 were being displayed indefinitely:
- **SBI Apprentice**: Expired 08 Jun 2026
- **CRPF Constable**: Expired 30 Jun 2026
- **IAF AFCAT**: Expired 15 Jun 2026

The system had no date validation, allowing expired jobs to clutter listings.

---

## Solution

### New Utilities (`src/lib/utils/dateUtils.ts`)

Added robust date parsing for "DD MMM YYYY" format with:
- `parseGovtJobDate()` - Parse and validate job dates
- `isJobExpired()` - Check if a date has passed
- `getExpirationStatus()` - Human-readable status

### Updated Services

**`src/lib/services/govtJobLocal.ts`**
- Added `filterActiveJobs()` to exclude expired entries
- Filters applied in `getGovtJobsLocal()` and `getGovtStatsLocal()`

**`src/lib/services/govtJobService.ts`**
- Added `filterExpiredJobs()` for all query operations
- Filters applied to both Supabase and local fallback results
- Respects existing `status='active'` database constraint

### Cron Automation (`src/app/api/cron/govt-jobs/route.ts`)

- New `markExpiredJobs()` function calls RPC to update database
- Marks jobs as `status='expired'` when `last_date < TODAY`
- Runs alongside existing auto-update logic

### Database Migration (`supabase/migrations/20250610000009_mark_expired_govt_jobs.sql`)

- New RPC function `mark_expired_govt_jobs()`
- Safely parses date strings and updates status
- Callable via API endpoint for scheduled runs

## How It Works

### User Flow
```
GET /api/govt-jobs?tab=latest
  ↓
getGovtJobs("latest")
  ↓
Query Supabase: WHERE status='active' AND tab='latest'
  ↓
Apply filterExpiredJobs() → Remove jobs with lastDate < today
  ↓
Return only active jobs to frontend
```

### Nightly Cleanup (via cron)
```
GET /api/cron/govt-jobs (authorization header required)
  ↓
markExpiredJobs()
  ↓
RPC: mark_expired_govt_jobs()
  ↓
UPDATE govt_jobs SET status='expired' WHERE lastDate < today
  ↓
Next API call automatically excludes these jobs
```
